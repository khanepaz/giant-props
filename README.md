# Giant Props | ساخت وسایل غول‌پیکر

سایت پورتفولیو برای نمایش کارهای غول‌پیکر.

## ساختار فایل‌ها

```
giant-props/
├── index.html          ← صفحه اصلی (خودش از data.json می‌خونه)
├── data.json           ← همه اطلاعات پروژه‌ها اینجا قرار داره
├── images/             ← پوشه عکس‌ها
│   ├── 1.jpg           ← عکس بخش درباره ما
│   ├── 2.jpg           ← کاروسل - اسلاید اول
│   ├── 3.jpg           ← کاروسل - اسلاید دوم
│   ├── ...
│   └── 11.jpg          ← گالری
└── README.md
```

## چطور پروژه جدید اضافه کنم؟

### روش ساده و پیشنهادی (فعلاً بهترین راه با GitHub):

1. عکس جدید رو داخل پوشه `images` آپلود کن (مثلاً `12.jpg`)
2. فایل `data.json` رو باز کن
3. به آرایه `gallery` یا `featured` یک آبجکت جدید اضافه کن:

```json
{
  "id": 7,
  "title": "عنوان پروژه جدید",
  "description": "توضیح کوتاه",
  "image": "12.jpg"
}
```

4. کامیت و پوش کن.

صفحه اصلی خودش به‌صورت خودکار پروژه جدید رو نشون می‌ده.

## آیا می‌شه صفحه مدیریت (Admin) واقعی داشت؟

**پاسخ کوتاه:** به صورت کامل و خودکار با خود GitHub خام، **نه**.

GitHub یک سیستم فایل + گیت است و پنل ادمین داخلی برای آپلود عکس و تولید خودکار JSON ندارد.

### گزینه‌های واقعی:

| روش | سختی | توضیح |
|-----|------|-------|
| **ویرایش دستی data.json** (روش فعلی) | خیلی آسان | بهترین گزینه برای شروع |
| **Decap CMS (قدیمی Netlify CMS)** | متوسط | پنل ادمین واقعی روی GitHub Pages / Netlify |
| **TinaCMS** | متوسط | پنل بصری مدرن |
| **GitHub Actions + فرم** | پیشرفته | نیاز به توکن و تنظیمات بیشتر |

### پیشنهاد من:

فعلاً با همین ساختار `data.json` کار کن (ساده، سریع و کاملاً تحت کنترل خودته).  
اگر بعداً تعداد پروژه‌ها زیاد شد و خواستی پنل مدیریتی داشته باشی، می‌تونیم Decap CMS یا TinaCMS رو اضافه کنیم.
